# 注意力机制（Attention）技术演进全史（1982–2026）

> **一句话总结**：注意力的本质是「按内容动态寻址」（content-based addressing）——用查询去和一堆键做匹配，按匹配度加权取回值。四十多年来所有技术迭代，都在回答同一个问题：**如何在"保留全对全交互的表达力"与"把 O(n²) 的时间和 O(n) 的 KV 显存打下来"之间取平衡**。

**文档口径说明（重要）**

1. **时间以论文首次公开（arXiv v1 / 会议投稿）为准**，不以期刊见刊时间为准。
2. 每条技术同时给出两个"第一次"：
   - **首次提出（论文/模型）**：把该机制写进论文并做出实验的那个工作；
   - **首次规模化落地（模型）**：第一个把它推到主流大模型/产品里的模型（两者常不同，例如 GQA 论文 2023 年提出，但真正普及靠 Llama 2 70B / Mistral）。
3. **区分"数学变化"与"系统变化"**：FlashAttention 不改变注意力的数学结果（它是 exact 的），改变的是显存访问；MLA 改变的是表示；NSA/DSA 改变的是"看哪些 token"。三者常被混为一谈，本文分开标注。
4. 论文编号统一写作 `arXiv:xxxx.xxxxx`；少数只有技术报告/博客的（Llama 4、Qwen3-Next、DeepSeek-V3.2-Exp）单独注明。
5. 涉及"首个"的表述，凡有争议的（如 self-attention 的发明权）都会标出前驱工作，不做单方面断言。

## 每章的"深度标准"

每个重点技术按七段写，缺一段就不算写完。这也是判断某章是否"已升级"的唯一标准：

1. **困境的定量刻画**——不是"太慢"，而是"$n=8192$ 时比 RNN 贵 16 倍"这种能算出来的数。
2. **构造推导**——公式从哪来、维度怎么变、系数为什么是这个（例如 $\sqrt{d_k}$ 来自点积的方差 $d_k$）。
3. **设计取舍**——为什么是 A 不是 B，B 在当时为什么走不通。
4. **论文证据**——具体数字与消融（BLEU、加速比、KV 减少百分比），而不是"效果更好"。
5. **失效条件**——什么输入、什么规模、什么硬件下它会坏。
6. **落地谱系**——哪些公司的哪一代用了它、后来为什么换掉。
7. **论文出处**——正文每个技术都带可点击的 arXiv 链接（摘要页 + PDF 直链）；每章末尾附「本章参考文献」，按首次公开时间排序。无 arXiv 的（GPT-1、Llama 4、Qwen3-Next、DeepSeek-V3.2-Exp）**明确标注为官方报告，不伪造编号**。

**当前进度**：**第 0–15 章 + 附录全部按此标准完成**（2026-11-19）。每章都有推导、失效分析、可点击论文链接与章末参考文献。
